      Créer la clé sur GitHub↗

      Le bouton ↻ (ou tirer l'écran vers le bas) lance une vraie recherche de prix (LDLC, Materiel.net, Alternate, Grosbill, et Amazon, Cdiscount, Fnac… via Ledenicheur), en 1 à 2 minutes. Il faut pour cela une clé GitHub : nom « Veille RAM », Repository access « Only select repositories » → veille-ram, Permissions → Actions : « Read and write ». La clé reste uniquement sur ce téléphone.
